# Archivio documenti storici

Questa e' l'**unica directory archivio dichiarata** del tema Civic (issue
[#26](https://github.com/laraxot/theme_civic_fila5/issues/26)). Contiene file
superati rimossi dall'albero attivo di `docs/`:

- `00-INDEX-legacy.md` — residuo `.tmp` del vecchio indice (2026-09-24).
- `00-index.old.md`, `documentation-index.old.md`,
  `index.historical-bmad.old.md` — snapshot storici degli indici.
- `FOOTER-CSS-FIX-2026-04-02.md`, `copilot-redundancy-audit-2026-05-25.md` —
  report una tantum.
- `auth/`, `css/`, `design-comuni/`, `visual-analysis/`, `wiki/` — copie
  `.md.old` scartate nel 2026-04/05 (era Sixteen), spostate qui con il suffisso
  `.old` rimosso. I nomi dentro mantengono date e maiuscole di proposito:
  **l'archivio e' immutabile** e non segue la convenzione dei nomi.

## Regole

- Niente documenti nuovi qui: la documentazione viva sta in `docs/` e segue la
  convenzione dei nomi (minuscolo, trattini, niente date).
- Niente link dai documenti vivi verso questa directory, salvo quando serve a
  dichiarare esplicitamente che un contenuto e' storico.
- Per citare un documento archiviato in una nota storica va bene il percorso
  completo `docs/archive/...`.
