# Security policy

## Segnalare una vulnerabilità

Non aprire issue pubbliche per vulnerabilità, credenziali, dati personali o problemi sfruttabili.

Per una segnalazione riservata, usa la funzione **Report a vulnerability** nella scheda **Security** del repository. Includi:

- versione o commit interessato;
- ambiente e prerequisiti;
- passi minimi per riprodurre il problema;
- impatto osservato;
- eventuale proposta di mitigazione, senza allegare segreti o dati reali.

Se la funzione non è disponibile, contatta i maintainer dell'organizzazione Laraxot tramite un canale privato verificabile. Non inviare credenziali, token, coordinate private o dati di tenant.

## Ambito

Civic è un tema di presentazione. Le vulnerabilità relative a dati, autorizzazioni, workflow, notifiche o API appartengono al modulo Laraxot o all'applicazione ospitante: indica nel report quale componente è coinvolto.

## Gestione

I maintainer confermeranno la ricezione quando possibile, valuteranno impatto e riproducibilità, coordineranno una correzione e pubblicheranno la comunicazione solo dopo la disponibilità di una mitigazione.

Non è garantito un tempo fisso di risposta o di risoluzione.
